PHASE 2 PREVIEW — YOUR EXISTING MONTEREY STUDIO

Close any unsaved work in the Studio first.
Double-click Preview Phase 2.command. If macOS blocks it, right-click and Open.
The updater finds your existing AI Influencer Studio Monterey folder under Downloads, or asks you to select it.

It stops the app, creates a private database/source backup, and updates only the application source to a pinned Phase 2 snapshot. Your existing .env, database, credentials and assets are preserved. The existing starter reinstalls dependencies, applies the additive draft migration and opens your browser.

Use the same email and password. The starter copies the password to the clipboard again. Type the email first; then paste the password without copying anything else.

In the browser:
1. Choose Projects in the header. Create/select a project.
2. Choose Characters, then Create character.
3. Walk through the ten steps and try a custom appearance or signature imperfection.
4. Use Save & close, then Resume draft to return to it.
5. Review the seven mock profile documents, then Save character.
6. On the detail page open Character DNA and Visual Bible; edit, duplicate or archive if desired.

No paid AI keys are required. Mock profiles are templates, not real AI generation. Scenes, image/video generation and other later modules remain Planned.

This is a local preview of unmerged Phase 2 code. Nothing is publicly deployed and no PR is merged. This update does not upgrade your Node runtime; it preserves the existing Monterey Node 22 compatibility setup. CI uses Node 24. A physical Monterey machine is not available to the agent for testing this updater.

Backups contain private data and must not be shared. A backup restore on your actual Mac has not been tested; ask for help before attempting a manual restore. The updater never automatically resets or restores your database.
