# Agent guidance for docs/v2

Scope: documentation and planning files in this directory only. The repository root `AGENTS.md` remains applicable and must not be replaced.

- Treat V2 material as **draft product direction**. A planning document is not authorization to build features, connect providers, modify production billing or merge changes.
- Before a task, read `Architecture-essentials.md` and only the sections of `PRD.md` or `Architecture.md` relevant to that task. Then inspect the actual code and tests.
- Keep V1 phase status separate from V2 proposals and validate any claim that a feature currently exists.
- Prefer small scoped changes, concise task summaries and explicit acceptance tests. Keep existing data, versions, source assets and permissions safe.
- Use one underlying Character DNA: natural realistic defaults for Simple Mode; Advanced overrides that do not clear defaults or unrelated settings.
- Preserve explicit boundaries between permanent identity edits and scene-only looks.
- Never invent external provider balances, prices, model capabilities, success metrics or real video performance.
- No user secrets or private likeness images in documentation, code comments or logs. Follow consent and ownership rules for reference media.
- If current code conflicts with these notes, report it and request a scoped decision rather than guessing.
- Do not automatically edit unrelated files or merge a PR.
